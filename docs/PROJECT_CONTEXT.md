# 프로젝트 컨텍스트

## 서비스 개요

지도에서 부동산을 찾고, 다른 회원이 공유한 해당 등기 대상의 정보를 확인하며, 관심 등록한 대상에 등기변동 신호가 생기면 알림을 받는 웹 서비스다. 회원이 이미 확보한 등기 정보를 공동으로 활용하여 같은 부동산을 중복 열람하는 비용을 줄이고, 최초 열람 이후에 생기는 변화도 추적하는 것이 목적이다.

주요 사용자는 금융권 종사자와 대출 상담·심사 실무자, 공인중개사, 소유자, 임차인과 전월세 계약 예정자, 매수 희망자다. 지도에서 대상 부동산을 찾기 어려운 문제, 동일 등기 문서를 여러 사람이 유료로 확인하는 문제, 열람 후 권리관계 변화를 반복 확인해야 하는 문제에 초점을 둔다.

## 이용 흐름

1. 주소·지번·건물명으로 지도에서 위치를 찾는다. 토지, 건물 또는 집합건물의 동·호수 중 확인할 등기 대상을 선택한다.
2. 해당 대상에 공유된 문서나 권리관계 정보가 있는지 확인한다. 문서에 적힌 열람·발급 시각, 서비스 등록 시각, 마지막 변동 확인 시각을 각각 확인한다.
3. 확보한 문서가 있다면 PDF 또는 이미지로 등록한다. 대상 식별, 정보 추출, 마스킹과 검수를 거친 뒤 공유가 허용된 데이터가 해당 등기 대상에 연결된다.
4. 관심 등록한 대상은 변동 확인을 받는다. 새 등기신청은 접수 사실을 알리고, 등기가 완료되면 기존 문서의 갱신 필요 상태를 표시한다. 새 문서를 확보하면 그 문서에 근거해 권리관계와 금액을 갱신한다.

## 설계의 중심

- **지도와 등기 대상** — 지도상의 아파트 건물 하나에 여러 동·호수의 등기가 연결될 수 있다. 위치나 주소는 탐색에 사용하고 문서와 변동 사건은 검증된 부동산 고유번호에 연결한다.
- **문서와 변동 사건** — 문서는 열람·발급 시점의 기록이다. 변동 조회는 공급처가 관측한 신청·처리 상태를 제공한다. 문서 확보와 변동 확인이 따로 일어나므로 두 시점과 근거가 사용자에게 드러나야 한다.
- **공유와 모니터링** — 회원 참여가 쌓이면 열람할 수 있는 대상이 늘어난다. 모니터링은 같은 부동산을 여러 회원이 구독해도 대상별로 한 번 조회하고 관련 회원에게 전달한다.
- **초기 이용 가치** — 공유 문서가 없는 지역이나 건물도 지도 검색과 등기 대상 탐색 흐름을 제공한다. 해당 대상의 공유 등록 여부를 명확하게 표시한다.

회원제·무료·비영리 운영은 기획 목표다. 공유 가능한 정보, 원본 보관 여부, 이용 비용과 부담 방식은 별도로 검증해야 한다. 화면은 지도 탐색과 대상 상세 확인을 중심으로 구성한다. 위험도 분석, 전세사기 예방 분석, 담보 분석과 시세 연계는 향후 범위다.
