# 요구사항

아래 항목은 기획에서 정한 제품 동작과 초기 범위다. 외부 데이터 확보와 재공유에 관한 [검증 항목](RESEARCH.md)을 확인한 뒤 실제 제공 범위를 결정한다.

## 지도와 등기 조회

- 메인 화면에서 지도 탐색과 주소·지번·건물명 검색을 제공한다.
- 토지, 건물, 집합건물의 동·호수 단위로 등기 대상을 조회한다. 같은 지도 건물에 연결된 호수의 문서와 상태는 각각 표시한다.
- 부동산 상세에 기본 정보, 공유 자료 등록 여부, 허용된 문서 또는 구조화된 권리관계 정보, 변동 이력을 표시한다. 문서 열람·발급 시각, 등록 시각, 마지막으로 변동 여부 확인에 성공한 시각과 갱신 필요 여부를 구분한다.

## 회원과 문서 공유

- 회원가입과 로그인을 제공한다. 마이페이지에서 본인이 공유한 정보, 관심 부동산, 계정 설정을 확인할 수 있다.
- PDF 또는 이미지로 등기 문서를 등록하고 추출·검수 과정을 거친다. 추출 범위는 부동산 고유번호, 주소, 표제부·갑구·을구, 열람·발급 일시, 소유권 이전, 근저당권 설정·말소 및 채권최고액, 압류·가압류·신탁 등 권리관계다.
- 문서를 정확한 등기 대상에 연결하고, 같은 문서의 중복과 다른 시점 문서의 버전을 구분한다. 대상 식별과 검수를 모두 마친 데이터 중 공유가 허용된 범위만 다른 회원에게 제공한다.
- 원본과 공유용 데이터를 구분하고, 개인정보 마스킹·검수와 접근 권한을 적용한다.

## 모니터링과 알림

- 회원은 여러 부동산을 관심 등록·해제하고 목록에서 모니터링 상태와 알림 설정을 확인할 수 있다.
- 주기적 외부 확인은 부동산 고유번호 단위로 중복을 제거한다. 확인한 사건을 저장하고 해당 부동산을 관심 등록한 회원에게 알린다.
- 신규 등기신청과 처리 상태 변경을 추적한다. 감지 목표에는 소유권 이전, 근저당권 설정·말소, 압류·가압류, 가처분, 신탁등기, 경매개시결정 및 기타 권리관계 변경이 포함된다. 세부 유형은 제공 데이터에서 확인 가능한 범위로 표시한다.
- 서비스 내 알림 센터에서 변동 내역과 상세를 제공하고 카카오톡 알림톡을 연동한다. 확인 주기는 오전·점심·오후 하루 세 번을 초기 목표로 두며 공급처의 갱신 주기, 이용 조건과 비용 확인 후 결정한다.

## 상태 표시 기준

문서 등록 여부, 최근 조회 결과, 신청 처리 상태는 함께 표시할 수 있다. 예를 들어 기존 문서가 등록된 상태에서 최근 조회가 실패할 수 있다.

| 상태 또는 사건 | 표시·처리 기준 |
| --- | --- |
| 공유 문서 미등록 또는 등록 완료 | 해당 등기 대상의 공유 자료 유무를 표시한다. |
| 최근 조회에서 변동 미감지 | 조회 시각과 미감지 결과를 표시하고 기존 문서를 유지한다. 문서의 기준 시점은 그대로 표시한다. |
| 신규 등기신청 진행 중 | 접수 또는 확인된 처리 상태를 표시하고 관심 회원에게 알린다. |
| 등기 완료 감지 | 기존 등기 정보에 갱신 필요 상태를 표시한다. |
| 새 문서 확보 | 검수 후 새 버전의 권리관계와 금액을 반영한다. |
| 변동 확인 실패 | 실패 상태를 표시하고 마지막 성공 확인 시각을 보존한다. |
