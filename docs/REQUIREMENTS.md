# 요구사항

## 1. 핵심 화면 구성 (4개 메뉴)

| 메뉴 | 목적 | 핵심 동작 |
| --- | --- | --- |
| **등기 검색** | 주소·건물명·고유번호로 공유된 등기 찾기 | 대형 검색창 즉시 검색, 최신 발급일시/소유자(마스킹)/근저당 요약 확인, **PDF 뷰어 바로 보기**, **변동 알림 켜기** |
| **등기 공유 (+P)** | PDF 단건·대량 업로드로 데이터 축적 및 포인트 적립 | 1~200개 PDF 드래그&드롭 투입, 고유번호·주소·발급일·주민번호 노출 자동 스캔, 중복/차단 사전 표시, 일괄 등록 및 포인트 적립 |
| **내 관리 물건** | 금융권 대량(200건) & 개인(1건) 변동 모니터링 | 상태별 요약 카드(전체/변동 감지/갱신 필요/정상), 테이블 검색·필터, CSV/고유번호 일괄 등록, 물건별 메모, 알림 채널 선택(앱 내/알림톡/문자), 변동 확인 실행 |
| **알림 & 포인트** | 변동 알림 수신 및 포인트 적립/사용 내역 확인 | 읽지 않은 알림 배지 및 타임라인, 포인트 잔액 및 입출금 원장 내역 |

## 2. 등기 PDF 업로드 및 열람 기준

- 업로드 형식은 인터넷등기소 전자발급 PDF(건당 5MB 이하)를 지원하며, 다중 파일 일괄 선택 및 드래그&드롭을 지원한다.
- 텍스트 추출로 **부동산 고유번호, 주소, 열람·발급일시**를 자동 식별한다.
- **개인정보 안전장치**: 주민등록번호 13자리(미마스킹)가 노출된 PDF는 공유 업로드를 차단하거나 경고 표시한다. 주민등록번호 뒷자리가 마스킹(`*******`)된 일반 열람·발급 PDF만 공유한다.
- **중복 방지**: 동일 `property_id` + `file_sha256` 파일은 중복으로 판별해 재적립을 막는다.
- **PDF 뷰어**: 공유 등록된 문서는 Private Storage에 보관하고, 인증된 열람 요청 시 서명된 임시 URL(Signed URL) 또는 안전 스트림으로 브라우저 내장 PDF 뷰어에 표시한다.

## 3. 포인트(크레딧) 정책 (설정 기반)

초기에는 `src/lib/points-config.ts`에서 단가와 동작 모드를 제어하며, UI 흐름을 먼저 검증한다.

- 신규 가입 웰컴 포인트 (`WELCOME_BONUS`)
- 등기 PDF 공유 적립 (`UPLOAD_REWARD`) — 중복·실패 건 제외
- 등기 PDF 열람 차감 (`VIEW_COST`) — 본인이 올린 문서 또는 이미 열람한 문서는 무료 재열람
- 변동 알림 구독 차감 (`MONITOR_COST`)

## 4. 변동 모니터링 및 알림 기준

- 동일 부동산을 여러 회원이 구독하더라도 확인 회차당 고유번호별 1회 조회 후 활성 구독자에게 알림을 전달한다.
- `신청 접수(received)`와 `등기 완료(completed)`를 구분한다. 등기 완료가 감지되면 기존 PDF에 **갱신 필요** 상태를 표시한다.
- 외부 조회 실패 시 마지막 성공 시각을 유지하며, 실패를 변동 미감지로 처리하지 않는다.
- 실제 외부 변동 조회 공급처(인터넷등기소/민간 API)가 확정되기 전까지는 교체 가능한 Provider 인터페이스 뒤에 모의 변동 확인을 연결한다.
