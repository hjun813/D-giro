# MVP 개발 계획서 (리빌드)

## 목표

지도와 부가 기능을 덜어내고, **등기 공유(대량 PDF 업로드) → 포인트 적립 → PDF 뷰어 열람 → 관심 물건(200건/1건) 변동 알림**으로 이어지는 핵심 제품 루프를 깔끔하고 직관적인 UI로 완성한다.

## 구현 범위

| 영역 | 구현 내용 | 연동 방식 |
| --- | --- | --- |
| **등기 검색 & PDF 뷰어** | 주소·건물명·고유번호 통합 검색, 최신 등본 카드, 내장 PDF 뷰어 모달 | Supabase DB + Private Storage Signed URL (+ 데모 샘플 PDF 폴백) |
| **대량 등기 공유 (+P)** | 다중 PDF 드래그&드롭(수십~수백 건), 클라이언트 순차/병렬 파싱 프리뷰, 주민번호 노출 차단, 일괄 등록 및 포인트 적립 | `POST /api/documents/parse`, `POST /api/documents`, `unpdf` |
| **내 관리 물건 (변동 알림)** | 200건 대응 관리 테이블, 상태 필터, 메모, 알림 채널 설정, 일괄 등록, 변동 확인 실행 | Supabase `watchlists`, `change_events`, `notifications` (+ 비로그인 로컬 체험 모드) |
| **포인트 원장** | 설정 기반(`points-config.ts`) 적립/차감 기록, 헤더 잔액 표시, 입출금 내역 | Supabase `point_ledger` (+ 비로그인 로컬 체험 모드) |
| **회원 인증** | 이메일 로그인/회원가입 (Supabase Auth) + 비로그인 시 즉시 체험 가능한 데모 모드 병행 | Supabase SSR Auth |

## 검증 기준

1. 검색창에 주소·건물명·고유번호를 입력해 등기 대상을 찾고, 클릭 한 번으로 PDF 뷰어에서 등기부등본 원문을 볼 수 있다.
2. 여러 개의 PDF 파일을 한 번에 드래그&드롭하면 고유번호·주소·발급일·중복·개인정보 안전 여부가 목록으로 분석되고, 일괄 등록 시 포인트가 적립된다.
3. 관리 물건 목록에서 다수의 부동산(금융권 200건 시나리오)을 검색·필터링하고, 변동 확인 실행 시 접수/완료/실패 상태와 알림이 정확히 기록된다.
4. `npm test`와 `npm run build`가 오류 없이 통과한다.
