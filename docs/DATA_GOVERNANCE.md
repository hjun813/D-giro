# 등기 자료 및 개인정보 처리 기준

공유 자료의 범위와 처리 절차를 정하기 위한 검토안이다. 원본과 추출 정보의 처리 가능 여부는 [법적·운영 검증](RESEARCH.md) 결과를 [결정 기록](DECISIONS.md)에 남긴다.

## 정보 유형별 검토

| 정보 | 이용 목적 | 접근·보관 검토 |
| --- | --- | --- |
| 원본 PDF·이미지 | 대상 식별, 정보 추출, 진위와 마스킹 검수 | 보관 가능 여부, 보관이 필요하다면 접근 주체와 보관기간, 삭제 방법을 결정한다. 검수 중인 원본을 회원 공유 화면에 연결하지 않는다. |
| 추출된 전체 정보 | 문서·대상 대조, 권리관계 구조화, 검수 | 검수에 필요한 필드와 접근자를 정한다. 원본과 별도로 남는 파싱 결과, 오류 메시지, 작업 임시 파일도 검토한다. |
| 마스킹 사본 및 공유용 필드 | 회원이 볼 수 있는 등기 정보 제공 | 항목별 공개 가능 여부와 범위를 확인한다. 마스킹 적용 이후 숨은 텍스트, 이미지, 문서 속성에서 가려야 할 정보가 남는지 검수한다. |
| 관심 목록·알림 설정 | 구독 관리와 알림 발송 | 본인에게 필요한 정보와 운영 처리 시 필요한 범위를 구분한다. 발송 수신 정보와 알림 내용의 외부 전달 범위를 확인한다. |
| 변동 조회·운영 기록 | 사건 이력, 조회 장애와 비용 확인 | 확인 시각과 결과를 남기되 공급처 응답 원문, 문서 내용, 수신 정보를 운영 로그에 저장할 필요가 있는지 별도로 검토한다. |

## 접근 주체 검토안

| 주체 | 접근 범위 |
| --- | --- |
| 일반 회원 | 공개가 결정된 공유 자료와 본인의 관심 목록·알림에 접근한다. |
| 제출 회원 | 본인이 올린 자료의 처리 상태를 확인한다. 원본을 다시 열람하거나 내려받을 수 있는지는 정책으로 정한다. |
| 권한을 부여받은 검수 담당자 | 검수 업무에 필요한 범위에서만 제출 자료와 추출 정보를 확인한다. |
| 운영 담당자 | 장애와 발송 상태를 확인한다. 원본 접근을 업무상 필요에 따라 별도로 검토한다. |

로그인 전 제공 범위와 실제 검수 운영 방식은 결정이 필요하다. 공유 여부 확인은 일반 화면, 직접 문서 열기, 다운로드 등 접근 경로에 일관되게 적용한다.

## 제출부터 게시 중단까지 확인할 흐름

1. 제출 시 고지할 처리 목적, 검수, 공유 범위와 철회·문의 방법을 검토한다.
2. 추출 후 선택한 대상과 문서의 고유번호가 일치하는지 확인한다. 출처·진위·마스킹 확인에 필요한 항목과 수동 검수 조건을 정한다.
3. 확인이 끝난 공유용 자료만 승인된 범위에서 노출한다. 게시 후 신고, 오연결, 마스킹 누락이 확인되면 접근을 중단하고 검수 후 처리하는 절차를 정한다.
4. 게시 중단, 철회, 정정, 회원 탈퇴 때 원본·공유 사본·추출 정보·캐시·백업에서 각각 무엇을 언제 처리할지 결정한다. 이미 발송한 알림의 상세 링크에서 게시 중단 상태가 반영되는지도 확인한다.

정식 정책을 확정할 때 정보 유형, 처리 목적, 접근 권한, 제3자 전달 범위, 보관 기간, 삭제·철회 처리와 담당자를 항목별로 기록한다.
