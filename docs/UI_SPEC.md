# 화면별 UI 명세

[디자인 시스템](DESIGN_SYSTEM.md)을 지도 탐색, 등기 대상 상세와 관련 화면에 적용하는 개발 전 검토안이다. 국내 부동산 지도에서 건물부터 동·호수까지 세부 정보를 좁혀 가는 탐색 방식을 참고한다. 등기로에서는 위치를 고른 뒤 화면의 주소·동·호수를 대조하고, 선택한 등기 대상의 문서와 변동 상태를 확인하는 데 초점을 둔다. [네이버 지도 부동산 지도 안내](https://help.naver.com/service/5637/contents/18775?lang=ko&osType=COMMONOS)

## 전역 배치

| 환경 | 헤더와 탐색 | 지도와 상세 |
| --- | --- | --- |
| PC 1,024 px 이상 | 높이 64 px 남색 헤더. 왼쪽에 로고, 오른쪽에 지도·관심 부동산·알림·내 정보. | 검색 결과와 상세를 폭 400 px의 왼쪽 패널에서 전환한다. 나머지는 지도에 배정한다. |
| 768~1,023 px | PC 헤더 메뉴를 유지한다. | 패널 폭을 320 px로 줄이고 긴 주소·상태 문구는 줄바꿈한다. |
| 모바일 767 px 이하 | 높이 60 px 남색 헤더에 로고. 검색 필드는 지도 상단, 1차 메뉴는 화면 하단에 배치한다. | 지도를 먼저 보여 주고, 검색 결과와 상세는 지도 위 하단 시트로 연다. |

1차 메뉴는 해당 기능을 제공하는 단계에 맞춰 노출한다. 계정 메뉴는 회원 상태에 따라 로그인 또는 내 정보로 표시한다. 모바일에서는 세부 기능 화면으로 이동하면 제목과 `뒤로` 동작을 제공한다. 메뉴·시트·주요 버튼은 휴대전화의 안전 영역을 고려해 배치한다.

## 지도 탐색 화면

```text
PC
상단     [등기로 로고]                       [지도] [관심 부동산] [알림] [내 정보]
         ─────────────────────────────────────────────────────────────────────
왼쪽     주소·지번·건물명 검색        │   오른쪽    지도와 위치 마커
         검색 결과 / 등기 대상 상세   │             확대 / 축소
         주소와 동·호수             │             지도 출처
         공유 자료와 기준 시각       │
         변동 확인과 관련 동작       │

모바일
상단      [등기로 로고]
검색      [주소·지번·건물명 검색]
지도       지도와 위치 마커        [확대 / 축소]
          ─────────────────────────────────
하단 시트  검색 결과 / 대상 상세     [닫기]
          주소와 동·호수           [주요 동작]
          ─────────────────────────────────
메뉴      [지도] [관심 부동산] [알림] [내 정보]
```

- 검색 결과 행에는 건물명 또는 대표 주소를 먼저 표시하고, 지번 등 구분에 필요한 주소를 다음 줄에 표시한다. 검색이 진행되는 동안 기존 선택을 유지하고, 결과 없음이나 검색 오류를 검색 영역에 표시한다.
- 결과 행과 지도 마커의 선택 상태를 연동한다. 마커는 위치 단위로 표시하고, 한 위치에서 확인한 여러 등기 대상은 패널이나 시트의 후보 목록에서 고른다. 집합건물은 `동 선택`, `호수 선택`을 표시하고 선택을 변경하면 대상 상세와 관련 동작도 함께 바뀐다.
- 선택한 위치는 지도 위 테두리와 목록의 강조로 함께 표시한다. 위치 마커의 공유 여부 표시는 정책상 제공 가능한 결과에 한해 검토한다. 동·호수별 공유 여부는 대상 목록이나 상세에서 표시한다.
- 모바일 시트는 주소와 다음 동작을 볼 수 있는 요약과 스크롤 가능한 확장 상태를 제공한다. 드래그 외에 `펼치기`와 `닫기` 버튼으로도 조작할 수 있게 한다. 확장 상태에서는 시트 안에서 목록을 스크롤한다.
- 패널이나 시트를 닫으면 검색어, 후보 목록과 지도의 위치·축척을 유지한다. 지도 조작 버튼과 공급처 출처 표시는 시트가 열려 있을 때도 보이는 영역에 배치한다. 지도를 불러오지 못해도 검색 결과를 확보할 수 있으면 목록에서 대상을 탐색하게 한다.

## 등기 대상 상세

| 순서 | 영역 | 표시와 동작 |
| --- | --- | --- |
| 1 | 등기 대상 | 건물명 또는 대표 주소, 토지·건물·집합건물 유형, 해당 동·호수. 후보 목록으로 돌아가 다른 대상을 고를 수 있다. |
| 2 | 공유 등기 자료 | 자료 있음·없음, 열람·발급 시각, 서비스 등록 시각, 갱신 필요 여부. 자료가 있으면 `공유 등기 보기`, 자료가 없고 제출이 가능하면 `등기 자료 공유`를 주요 동작으로 표시한다. |
| 3 | 권리관계 | 공개가 허용된 범위에서 표제부·갑구·을구 항목을 나누어 보여 준다. 권리 종류, 설정·말소 상태와 출처 문서의 기준 시점을 구분한다. 금액은 항목명과 함께 표시한다. |
| 4 | 변동 확인 | 마지막 성공 확인 시각, 최근 조회 실패 여부, 확인된 신청 접수·완료 사건을 각각 표시한다. 확인 이력이 없으면 `확인 이력 없음`으로 안내한다. |
| 5 | 관심 등록 | 모니터링이 제공되는 대상에 `관심 등록`을 표시한다. 등록한 뒤에는 `관심 등록됨` 상태와 설정·해제 가능한 동작을 제공한다. |

`발급 시각` 또는 `열람 시각`은 자료에 적힌 기준을 사용한다. `서비스 등록`과 `마지막 확인 성공`은 별도 줄에 표시한다. 확인 실패와 갱신 필요가 함께 발생하면 문서 영역과 변동 확인 영역에 각각 표시한다. 조회 불가, 추출 미확인, 공개 제외는 확인된 자료 없음과 구분해 실제 이유를 표시한다.

## 관련 화면

| 화면 | 배치 | 필요한 상태와 동작 |
| --- | --- | --- |
| 등기 자료 공유 | 작업 제목과 선택한 주소·동·호수를 상단에 고정해 확인할 수 있게 한다. 아래에 파일 선택, 선택 자료 및 처리 안내, 제출 버튼을 순서대로 놓는다. | 미선택, 업로드 중, 제출 완료, 대상 불일치, 파일 오류, 검수 중을 구분한다. 검수 완료 여부는 제출 결과와 내 정보의 `내가 공유한 자료`에서 확인한다. |
| 관심 부동산 | 제목 아래에 대상 목록을 배치한다. 이름과 동·호수를 먼저 표시하고, 각 행에 최근 확인 결과와 마지막 성공 시각을 표시한다. | 행을 누르면 해당 등기 대상 상세로 이동한다. 알림 설정과 관심 해제는 각 행의 명시적인 동작으로 제공한다. 빈 목록에는 지도로 이동하는 동작을 둔다. |
| 알림 | 최근순 목록에 주소·동·호수, 사건 또는 처리 상태, 확인 시각을 표시한다. | 읽지 않은 항목은 글자 굵기와 읽음 상태로 구분한다. 항목을 열면 관련 사건을 확인할 수 있는 상세로 연결한다. |
| 로그인·가입 | 제목, 입력란, 필드 오류, 주요 버튼이 한 방향으로 이어지게 배치한다. | 로그인 때문에 제출·관심 등록을 중단했다면 로그인 후 원래 대상과 작업으로 돌아갈 수 있게 한다. |
| 내 정보 | `내가 공유한 자료`, `관심 부동산`, `계정 설정`을 분리된 목록 행으로 보여 준다. | 제출 이력에서 처리 상태를 확인한다. 자료 열기와 다운로드는 승인된 접근 범위에 맞춰 표시한다. |

## UI 검수 기준

- PC 1,280 px, 중간 800 px, 모바일 390 px와 좁은 320 px에서 대표 흐름을 확인한다. 주소가 길거나 글자 크기를 키웠을 때 핵심 정보와 실행 버튼의 의미가 유지되는지 확인한다.
- 지도 선택과 검색 결과의 활성 상태, 접힌 시트와 펼친 시트, 상세를 닫은 뒤 검색 위치 유지, 키보드로 검색부터 대상 선택까지 이어지는 동선을 확인한다.
- 공동주택의 두 호수를 번갈아 선택해 주소·자료·관심 상태가 맞는지 확인한다. 자료 미등록, 대상 확인 불가, 최근 조회 실패, 갱신 필요의 화면 문구와 동작을 각각 확인한다.
- 흰 지도 타일, 어두운 지도 영역, 지도가 로드되지 않은 상태에서 마커·조작 버튼·텍스트와 선택 표시를 확인한다. 색을 구분하기 어려운 상황에서도 상태 문구를 읽을 수 있어야 한다.
- 상세와 업로드의 로딩·실패·완료 상태, 모달을 닫은 뒤 초점 복귀, 모바일 시트와 브라우저의 안전 영역을 확인한다. 기능 시나리오는 [MVP 인수 기준](ACCEPTANCE_TESTS.md)을 참조한다.
