# 등기로 MVP

지도 검색, 가상 등기 자료 조회·공유, 관심 등록과 모의 변동 알림을 검증하는 로컬 웹 앱입니다. 등기 대상·문서·변동 사건은 검증용 가상 자료이며, 테스트 사용자별 상태는 브라우저에 저장됩니다.

## 실행

Node.js가 설치된 환경에서 실행합니다. 별도 패키지 설치 없이 시작할 수 있습니다.

```powershell
npm start
```

`http://localhost:4173/`에서 열립니다. 키 설정 전에는 검증용 지형과 위치 검색을 사용할 수 있습니다.

### 카카오맵 연결

개발자 앱에서 카카오맵을 사용할 수 있도록 설정하고, JavaScript 키에 브라우저에서 접속할 개발 도메인을 등록합니다. 기본 실행 주소는 `http://localhost:4173`입니다. JavaScript 키를 현재 PowerShell 세션에 설정하고 서버를 실행합니다. [카카오맵 이용 조건](https://developers.kakao.com/docs/ko/kakaomap/common) · [지도 Web API 가이드](https://apis.map.kakao.com/web/guide/)

```powershell
$env:KAKAO_MAP_JS_KEY = '<카카오맵 JavaScript 키>'
npm start
```

실제 지도가 열리면 지도에 `카카오맵`이라고 표시됩니다. API 응답으로 도로명·지번과 건물명을 검색하고, 검증용 위치로 등록된 공개 장소에서 가상 등기 대상을 열 수 있습니다.

## 대표 검증 흐름

1. `서울시청` 또는 `세종대로 110`을 검색합니다. `가상 101동 201호`와 `가상 101동 202호`의 자료를 각각 확인합니다.
2. 202호에서 `등기 자료 공유`를 선택한 뒤 201호 샘플과 202호 샘플을 차례대로 제출하여 대상 불일치와 정상 공유를 확인합니다.
3. 201호를 관심 등록한 뒤 `내 정보`에서 다른 테스트 사용자로 전환합니다. 같은 대상을 관심 등록하고 `변동 확인 실행`을 차례대로 누릅니다. 두 명이 관심 등록한 대상의 회차별 조회 횟수와 알림 건수를 볼 수 있습니다.
4. 등기 완료 이후 201호의 `문서 갱신 필요`를 확인합니다. `201호 완료 반영 자료` 샘플을 제출하면 해당 표시가 해소됩니다.
5. `내 정보`의 `검증 초기화`로 샘플 상태를 복원할 수 있습니다.

```powershell
npm test
```
